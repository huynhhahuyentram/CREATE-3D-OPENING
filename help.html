📖 User Guide

3D Opening Tool Pro Documentation

📖 Introduction

3D Opening Tool Pro is a design tool used to create and export MAC files for architectural openings. The application provides real-time 3D visualization and precise dimensional control.

📐 Technical Specifications

📏 Dimension

Enter Length, Width and Thickness in millimeters. The 3D model updates automatically.

📍 Position

Define X, Y and Z coordinates for placement.

🔄 Orientation

Select X, Y or Z axis orientation.

⭕ Corner Radius

Configure R1, R2, R3 and R4 individually.

💾 Export MAC File

  • Automatic export after completing parameters.
  • Voice export using "Save file".
⚠️ Important Notes
  • Measurement unit: mm
  • Microphone permission required for voice control.
  • Exported file format: .mac
  • Supports English and Vietnamese voice commands.
  • Library data can be synchronized with Google Sheets.
